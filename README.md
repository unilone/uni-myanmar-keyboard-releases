# Uni Myanmar Keyboard: downloads

Downloads of **Uni Myanmar Keyboard** for Mac: a floating Myanmar keyboard
with word suggestions, spell fixes, Zawgyi ↔ Unicode conversion,
translation and a dictionary.

## Install

1. Download `UniMyanmarKeyboard.dmg` from the [latest release](../../releases/latest).
2. Open it and drag **Uni Myanmar Keyboard** into **Applications**.
3. The first time, right-click the app and choose **Open** (it is not from the App Store).

The app checks this page once a day and tells you when a new version is out
(menu bar icon → **Check for Updates…**).
